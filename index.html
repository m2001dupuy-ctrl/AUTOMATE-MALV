Final Prompt Payload
▌ CONTEXT

You are a supply chain operations expert for a luxury maison. Design a simple, business-friendly Power Automate workflow using standard Microsoft connectors to generate standardized supplier email drafts from planning data. The workflow uses a single Excel file stored in SharePoint under: Documents > WORKSHOP AUTOMATE AI > FLOW_FILE.xlsx, containing an Excel table named "FlowSS27" with exactly the following columns: SEASON, COLL, SKU, DESCRIPTION, SUPPLIER, EMAIL, LAUNCH W, LAUNCH NEED W, BUYING, LAUNCH NEED, REAPPRO, FLEX, PO (where EMAIL contains the supplier email address directly on each row).

Objective:

  • Read planning data directly from the "FlowSS27" table in FLOW_FILE.xlsx (which already includes the supplier email address on each row in the EMAIL column).
  • Loop through each planning row.
  • Populate a fixed, standard email template with the row's data (no AI-generated text).
  • Produce the email in two blocks within the same message: Italian version first, English version underneath. Each block must contain: Season, Collection, SKU, Description, Launch W, Launch Need W, Buying, Launch Need, Reappro, Flex, PO.
  • Save each generated email directly into the user's Outlook Drafts folder (no automated sending, no human approval steps required).
▌ ACTION

Design the complete Power Automate flow architecture step by step. For each main step, specify:

  • Trigger / Action type: the exact Power Automate trigger, connector, or action
  • Explanation: what the step does
  • Action details: the specific configuration or data to insert
  • Expected output: what the step produces for the next stage
▌ FORMAT

Structure your response exactly as follows:

  1. EXCEL FILES FORMATTING (Explain any assumptions required if the Excel file is not already formatted as a proper Excel table named "FlowSS27" with clean column headers matching: SEASON, COLL, SKU, DESCRIPTION, SUPPLIER, EMAIL, LAUNCH W, LAUNCH NEED W, BUYING, LAUNCH NEED, REAPPRO, FLEX, PO. No lookup formula is needed since the EMAIL column is directly present in the file.)
  2. POWER AUTOMATE FLOW STRUCTURE (For each step: Action/Trigger | Explanation | Action Details | Expected Output)
  3. EXAMPLE SUPPLIER EMAIL (show the Italian block, then the English block, both populated with sample SEASON, COLL, SKU, DESCRIPTION, LAUNCH W, LAUNCH NEED W, BUYING, LAUNCH NEED, REAPPRO, FLEX, PO data)
▌ FILTERS
  • Keep the solution simple, short and accessible for non-technical business users. Maximum 4 steps.
  • Use only standard Microsoft 365 / Power Automate actions (Excel Online (Business), SharePoint, Outlook Draft actions) — do not use AI Builder, Azure OpenAI, or Copilot actions.
  • The email body must be a fixed, standard template, not AI-written; dynamic content is limited to inserting retrieved data values into the template. It should contain both language versions: Italian first, English underneath, same structure and same data.
  • Factual data (SEASON, COLL, SKU, DESCRIPTION, SUPPLIER, EMAIL, LAUNCH W, LAUNCH NEED W, BUYING, LAUNCH NEED, REAPPRO, FLEX, PO) must come strictly from the "FlowSS27" table in FLOW_FILE.xlsx and must never be invented or altered.
  • Do not include complex array filtering, distinct unions, filtering the excel file for missing info or manual approval gates; rely on a streamlined row-by-row loop that saves directly to Outlook Drafts.
  • Use the Outlook draft action (e.g., Draft an email message) so emails sit in the Drafts folder for manual review and sending, do not compose just write the email directly in Draft message.
